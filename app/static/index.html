Формат ответа

По каждому ковенанту каждого заёмщика — 3 компонента. Структура строго по submission_template.json.

submission.json
{ "team": "wit.kz", "contact_email": "info@wit.kz", "model": "muse-spark-1.2-contributor", "answers": { "P1": { "6.1": { "status": "COMPLIANT", "actual": 1.68, "evidence_txn_id": null }, "6.2": { "status": "BREACH", "actual": 5400000.00, "evidence_txn_id": null } } } }
①

Вердикт — status

COMPLIANT или BREACH • заглавными

②

Число — actual

Положительное, USD или коэффициент • 2 знака после запятой

③

Транзакция-улика — evidence_txn_id

Единственная спорная TXN-* или null (коэффициенты/агрегаты)

⚙️ Настройки

Провайдеры: ключ muse-spark хранится в .env (MUSE_SPARK_API_KEY) или cache/providers.json. Для хакатона достаточно env.
